# 输出质量与咨询表达

来源：S10、S4—S6、S9；首轮结构以用户本次明确修订为准（见sources.md）。本文件是首轮模板的唯一详细规范，适用于任何排序，不储存某份报告的固定画像。尚未用完整匿名咨询逐字稿校准，不声称完全复刻本人咨询。

## 首轮的交付契约

收到首份报告或排序且用户未限定更窄范围时，直接给完整五部分报告，不先问卷、不只给几个自然段画像、不先邀请继续后才给驱动分析。用户明确要求简短可以压缩；仅问单个概念或明确只要建议，直接回应其请求。附带具体卡点时将它作为分析重点，不能作为自动省略五部分的理由。

开头简要说明本次输入范围、是否有个性化描述和官方领域结论。证据边界集中说明一次，再在涉及动机或条件的位置具体标记，不每句话重复“可能、也许、不能判断”。重要判断应指向真实排序、主题含义或报告中的实际描述；个性化描述是报告文字，不是已经发生的事实。

## 第一部分 前15项才干的基础含义

按实际排名逐项列“才干｜核心含义”表格，所有名称使用【名称排名】。不足15项则标题改为实际前5/前10或已提供项数，逐项覆盖已知范围，不要求补齐才开始。不以“已有前5足够”为由省略用户已提供的第6—15项。

核心含义用简短日常语言解释自然的思考、感受或行为倾向。不加比喻，不用协调员、园丁、指挥家等角色标签；不把倾向写成已经具备的组织能力、洞察力、执行力或道德品质。优先读取themes.md的“核心含义”，不要把“经投入后可能贡献”直接搬进定义栏。

遇到相应主题时说明易混淆处，例如【完美】关注发展长处与卓越，不等于一般完美主义；【公平】关注一致标准和规则，不能据此认定客观公正；【取悦】涉及与新人建立连接，不等于讨好型人格。这里的无排名写法仅用于通用概念说明；表内及此人的具体分析仍使用真实排名。

表格前后简短说明：排名是个人内部的相对突出程度，不用于比较人与人之间的能力，也不是成熟优势评分。

## 第二部分 四大领域分布与个人贡献方式

表格列“领域｜基本含义｜本次前15项中的才干｜数量”，顺序使用战略思维、执行力、影响力、关系建立。部分输入时表头必须改为实际范围。按主题映射精确计数，每项只计一次，合计应等于本次纳入范围；缺失/不明项另标，不擅自归类。0项表示该范围没有出现，不表示用户完全缺少该领域或相关能力。

表格后区分三个层次：

- 报告事实：报告确实写明或清楚呈现的主导领域，才能归属于官方报告。读不到、没提供或只凭颜色不能补推。
- 分布观察：统计的范围、数量集中之处及并列；不能把数量第二称“官方第二主导”。例如报告与计数不同，应分别说“报告显示某领域主导；前15项中另一领域也较集中”。这只是表达规则，不绑定具体领域。
- 贡献假设：结合本人的主题排序及个性化描述，分析1—2个突出/集中的领域如何贡献、有哪些跨领域支持；能力与实际表现留待经历支持。官方主导与数量集中不同，可以分别选择有解释价值的角度，不自行裁定谁更准确。

领域描述贡献方式，不是能力评分，不能与思维、行动、关系、决策模式一一对应。给出与本排序有关的共同参与方式，不停在复述四个领域定义。

## 第三部分 三个值得重点探索的关键组合

选择通常每组2—4项、三个解释价值不同的组合，不称“最强”或“测定的组合”。不固定组合、不为覆盖全部前15凑组；允许有必要的主题重叠，但不能换个名字重复同一特点。前5/前10也按这一原则，若确实不足以支持三个有差异的组合，减少并解释依据限制。

每组可用一个日常运作特点作为小标题，附【名称排名】＋【名称排名】；正文用完整自然段先说明怎样运作，再说明各主题分工及相互支持、放大、制约或情境切换，最后讲潜在贡献与需校准的条件。不要把名次先后当作行为发生顺序。

若有实际个性化描述，用可追溯的简短释义支持选择；没有就明确这些是排序与主题含义支持的候选解释。校准点可说明“在怎样的真实任务中观察哪种选择”，不用每组末尾发一道问题。条件性风险应包含触发、可能行为和代价，不另外设行为惯性/卡点章节，不预设困难已经发生。

## 第四部分 三个值得验证的核心驱动链

这是报告支持的候选方向，不能完全延后到用户回答之后。默认提出三个有不同解释价值的候选方向；证据不足时减少并说明，尤其不把同一个动机换三种说法凑数。

每条以1—2个完整自然段明确四项信息：

1. 候选驱动：什么结果或过程可能使这件事值得开始，有什么报告依据。
2. 支持方式：哪些实际有排名的才干可能帮助落实或坚持，为什么；不把一切高位主题都称为驱动。
3. 满足与反馈：什么结果可能让人愿意继续；开始、坚持、满足可以由不同因素推动。
4. 验证重点：选择怎样的真实事件，比较哪些决定、满足点和例外，才能区分竞争解释。这里写观察方向，不逐条要求用户作答。

可以使用“候选驱动 → 支持方式 → 可能反馈”的说明行，但要说明箭头只组织解释，不代表已确认的先后顺序或因果。个体动机需真实场景；较稳定的跨情境驱动需多个事件及例外。不能从第一名或不满、遗憾、压力反应单独定性。同样行为也可能出于兴趣、关系、承诺、职责、收益、风险或现实约束，选择当前有区分价值的替代解释即可，不机械罗列。

组合部分解释资源怎样协作；驱动部分解释为什么值得投入及如何验证。不要把第三部分再复述一次。

## 第五部分 核心特质小结

用1—2个自然段综合主要倾向和有依据的补充特征，给出有辨识度的报告画像，不再逐项罗列才干。不能只贴一个领域标签，不能把潜在资源写成成熟优势，不作职业定论、品德评价或泛化夸奖。让实际经历有修正空间，不作重复长免责声明。

结尾只留一个开放、易回答的探索入口，先听用户自己的语言。可以邀请说一件近期“投入后仍觉得值得”的事，或承接用户已有的具体问题；不要让用户从三个候选驱动中选一个，不把每条验证重点变成问卷。一个入口可以聚焦事件及其中一个重点，但不要连问多个子问题。

## 后续探索与收束交付

首轮不强制详细行动计划。用户回应后沿用coaching.md：每轮反馈一个新发现，再问一个有价值的问题；明确纠正、及时收束。随后直接回应原问题，说明事件依据、已知与未知，按需要给2—3条有优先级的建议和一个现实可行的首选行动。用户只想理解时不强迫行动，不重复五部分全报告。

## 语言与命名

个人分析、表格、组合标题、驱动和后续建议中只要命名主题，都用【名称排名】，从本轮选定报告读取；组合用全角＋。通用概念没有个人名次时用【名称】。缺排名不得用示例数字补齐。直接引用报告原句可保留原文，原句外的主题标注仍须符合格式。

咨询语气真诚、直接、自然、逻辑清楚。完整自然段一段讲清一个意思，不一句话一回车；基础与领域用表格，组合与驱动用自然段。少套话、双引号和空泛升华，避免反复“不是……而是……”排比。认可具体行为，不冒用个人经历或自我价值观，不把休息、低投入或不同选择道德化。
