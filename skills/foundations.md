# 基础理论与输入处理

来源：S1、S2、S3、S7、S8、S9、S10；核心概念及四领域名称另参照O1—O3，来源编号见 sources.md。以下是工作性释义，非官方报告逐字翻译。

## 才干、优势与能力

才干指自然、反复出现的思考、感受与行为倾向。优势指在具体活动中形成稳定高质量表现的能力，需要知识、技能、练习和反馈投入。用“才干×投入→优势”说明发展关系，不将它当成能量化计算的科学公式。能力须通过实际表现判断，不等于某个才干名次。

“我经常主动整理信息”是行为线索；“搜集指对资源与信息的获取储备倾向”是主题释义；“你在这次项目中搜集，是为了降低决策不确定性”是待验证解释。这三种内容不能互相替代。

弱点指正在妨碍目标或结果的因素，可能来自技能不足、流程缺失、资源不够、情境不适配或某种倾向使用失衡。不能把后五名直接列为弱点。自然倾向也不能免除学习必要技能或遵守责任的需要。

## 四领域映射

| 领域 | 主题 |
|---|---|
| 执行力 Executing | 成就、统筹、信仰、公平、审慎、纪律、专注、责任、排难 |
| 影响力 Influencing | 行动、统率、沟通、竞争、完美、自信、追求、取悦 |
| 关系建立 Relationship Building | 适应、关联、伯乐、体谅、和谐、包容、个别、积极、交往 |
| 战略思维 Strategic Thinking | 分析、回顾、前瞻、理念、搜集、思维、学习、战略 |

领域是帮助理解贡献方式的视角，不是能力测试成绩。任何领域的才干都可能帮助思考、执行、影响或关系建立；分布不均不意味着人格不完整，均衡也不意味着平庸。

只有前5时，可说“你提供的5项中有3项属于某领域”，不能说“你的完整领域中该领域最强”。即使有34项，也不把简单计数或自行设置权重伪装成官方领域得分。报告有领域图时忠实描述可辨内容，不补造算法。

## 首轮统计与名称

默认完整报告按output-style.md的五部分交付。提供34项时基础解释和数量统计使用实际前15；只有前5/前10时按已提供范围完成同样五部分，不补排序或推断完整分布。第16—34项在与问题确有关联时仍可引用，但不混进前15计数。

核验后建立本轮“主题→名次”对应，每次输出个人主题均渲染为【名称排名】。多份版本各自保留，只有用户选定的当前版可进入同一分析。未知名次不猜；通用概念释义用【名称】并注明不是已知排名。

领域表按战略思维、执行力、影响力、关系建立列含义、主题及数量，再分析1—2个有依据的突出角度。单独保留报告明确的主导领域文字/图示证据和前15计数，两者不能互换。“数量第二”只能描述该范围的集中程度，不能创造官方第二主导。领域不与思维、行动、关系、决策模式一一对应，同一任务可有多领域才干参与。

## 输入检查步骤

1. 识别文件类型与是否真的可读。对PDF/DOCX先读取文本，表格/截图须核对排序与对应文字；扫描PDF或模糊图像不能凭标题推断内容。工具不可用时请用户粘贴相关排序或文字，不谎称已读附件。
2. 分开记录来源状态、报告日期/版本、提供范围、原始排序、可确认的主题名与真实个性化描述。不同版本或个人信息不混并。
3. 用 themes.md 的中英文名校准。“统帅”等疑似别称有歧义时结合英文 Command 或向用户核对，不静默改写。Maximizer 的“完美”不等于临床或日常的完美主义，Woo 的“取悦”不等于讨好型人格。
4. 完整排序应有34个不同主题；部分排序保留其实际范围，不补全。重复主题、序号跳跃、名称不明时指出具体位置并确认；能确定的内容可继续有限解读。
5. 没有个性化描述时，用通用主题释义解释，不说“你的报告写道”。读到一般说明文字，也不能称它为用户独有描述。
6. 来源未确认时标记“你提供的排序/报告”，不凭版式宣称正版或盗版。多份结果说明差异及范围，请用户选择参考版；选择前不形成合并画像。

## 最小信息原则

首次报告默认完整五部分解读，首轮提出有依据的候选驱动；有问题围绕问题组织内容；只有报告疑点只处理疑点。已有上下文不反复索取排序。没有报告可以聊一个真实经历，关注投入、做法、结果与资源，但不逆推出官方排名。

年龄性别仅在用户主动提供且与约束相关时使用。时间、预算、技能、职责和风险承受能力只问会影响方案的部分。用户未提婚育，不能预设；男性与其他用户获得同样的咨询流程。不同对话间是否保留信息由平台决定，技能本身不建立用户档案。
